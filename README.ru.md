# mercurius-antigravity

Модели плана Google Antigravity для агента: официальный Antigravity CLI (`agy`) как одноразовый клиент одного вызова
модели, за интерфейсом Chat Completions. Модуль [Меркурия](https://github.com/opencck/mercurius) на
[AMPHP](https://amphp.org). Цикл агента, инструменты и подтверждения остаются у приложения: `agy` — только модель.

## Сначала прочтите: условия Google это запрещают

Условия Antigravity (раздел 6) и FAQ называют доступ к сервису через стороннее программное обеспечение и обёртку
`agy` в приложение нарушением, за которое аккаунты Antigravity и Gemini CLI могут быть приостановлены или закрыты.
Модуль по умолчанию выключен. Включайте его только на своём экземпляре и только если принимаете этот риск; отдельный
аккаунт Google ограничивает потерю, но риска не снимает. Разрешённые пути к Gemini для агента — ключ AI Studio и
Vertex: в Меркурии это провайдеры `gemini:` и `vertex:`, модуль им не нужен.

## Что он делает

- Один вызов модели — один процесс `agy` с одним промптом. Процесс получает агента вызова без встроенных
  инструментов; инструменты приложения ему перечисляет инертный MCP-сервер, который ничего не исполняет.
- Первый вызов инструмента приложения заканчивает вызов и снимает процесс: инструмент исполняет приложение. Шаг
  любого другого инструмента или откат `agy` на агента по умолчанию обрывает вызов ошибкой.
- История сворачивается в одно сообщение с разметкой, которую её собственное содержимое сломать не может.
- Квота плана спрашивается без вызова модели; исчерпанное окно отклоняет модели своей группы до запуска чего-либо.
- После вызова ничего не остаётся: процесс, запись беседы, которую вёл `agy`, и каталог вызова удаляются.

Чего он не делает: не меняет бинарь `agy`; не читает, не копирует и не пишет файл входа; не ходит к API Google сам;
не принимает ключ API и облачные учётные данные; не меняет аккаунты; не исполняет инструменты; не изображает
человека за терминалом.

## Состояние

Проверен на подставном `agy`. На настоящем `agy` 1.5.18 проверено только то, что видно без входа. См. `BRIEF.md`,
«Что не проверено».

## HTTP

Всё, кроме `/health`, требует `Authorization: Bearer <ANTIGRAVITY_TOKEN>`.

| Маршрут | Что |
|---------|-----|
| `GET /health` | 200 без входа, когда CLI найден и не старее нужного; иначе 503 |
| `GET /auth/status` | CLI, вход, ждёт ли вход кода |
| `POST /auth/login` | Запускает вход, возвращает ссылку и сколько ждёт `agy` |
| `POST /auth/code` | Передаёт код ожидающему `agy` |
| `POST /auth/logout` | 501: команды выхода у CLI нет |
| `POST /v1/chat/completions` | Один вызов модели, потоком или одним объектом |
| `GET /v1/models` | Модели плана с уровнями усилия и окнами |
| `GET /usage` | Квота плана |

## Настройки

| Переменная | По умолчанию | Что это |
|------------|--------------|---------|
| `ANTIGRAVITY_TOKEN` | — | Токен модуля, 16+ символов; обязателен |
| `ANTIGRAVITY_PORT`, `ANTIGRAVITY_HOST` | `8095`, `0.0.0.0` | Где слушает сервис |
| `ANTIGRAVITY_HOME` | `/data/antigravity` | Домашний каталог CLI: настройки, журнал, вход. Держите на томе, права 700 |
| `ANTIGRAVITY_COMMAND` | `agy` | CLI |
| `ANTIGRAVITY_MIN_VERSION` | `1.5.18` | Самая старая версия CLI, с которой работает сервис |
| `ANTIGRAVITY_IDLE_SECONDS` | `300` | Сколько вызов может молчать |
| `ANTIGRAVITY_MAX_CONCURRENT` | `2` | Сколько процессов `agy` работает одновременно |
| `ANTIGRAVITY_PROXY` | — | `socks5h://`, `http://` или `direct`; `VLESS_URI` важнее, если не задано `direct` |
| `ANTIGRAVITY_EGRESS_HOSTS` | — | Точные имена хостов через запятую, которые прокси сервиса открывает сверх своего короткого списка хостов Google |

Сервис отказывается стартовать, когда в его окружении есть `GEMINI_API_KEY`, `GOOGLE_API_KEY`,
`GOOGLE_APPLICATION_CREDENTIALS`, `GOOGLE_CLOUD_PROJECT` или `GOOGLE_GENAI_USE_VERTEXAI`: `agy` вошёл бы по ним и
считал расход по прайсу API вместо плана.

## Сборка и запуск

```bash
docker build -t mercurius-antigravity .
docker run --rm -e ANTIGRAVITY_TOKEN=... -v "$PWD/data:/data/antigravity" -p 127.0.0.1:8095:8095 mercurius-antigravity
```

Сборка скачивает закреплённый `agy` у Google и сверяет его sha512. Не выкладывайте образ в открытый реестр: бинарь
распространять не нам.

## Проверки

```bash
composer check   # PHPUnit, PHPStan (max), Psalm (уровень 1); подставной agy, без входа и без сети
```
